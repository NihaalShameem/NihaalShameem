Try it now

Here's the dataset's heartbeat — daily Gross Gaming Revenue (GGR = stakes − payouts). Run the SQL cell, then the Python cell. Same data, two tools you already use.

SELECT product, ROUND(SUM(stake) - SUM(payout), 0) AS ggr, COUNT(*) AS num_bets FROM bets GROUP BY product ORDER BY ggr DESC;
# Join bets to the players who made them, then roll up revenue by channel m = bets.merge(players[["player_id", "acquisition_channel"]], on="player_id") m["ggr"] = m["stake"] - m["payout"] summary = (m.groupby("acquisition_channel")["ggr"] .agg(["sum", "mean", "count"]) .sort_values("sum", ascending=False) .round(2)) print(summary)
