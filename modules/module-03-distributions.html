Probability Distributions

A distribution is the "shape" of randomness — it tells you which values are likely and which are rare. Learn the handful of named distributions in this module and you'll recognize them everywhere in iGaming: a single bet, a parlay, bets-per-day, session lengths, deposit sizes, and daily revenue each have a characteristic shape with a name.

🎯 What you'll be able to do

  • Tell a discrete random variable from a continuous one.
  • Model a single yes/no outcome with Bernoulli and counts of them with the Binomial.
  • Model event counts per period (bets/day, arrivals) with the Poisson.
  • Use the Normal distribution, z-scores, and the 68–95–99.7 rule.
  • Model waiting times with the Exponential, and skewed money with the Log-normal.
  • Drive all of this with scipy.stats: pmf, pdf, cdf, mean, rvs.

3.1  Random variables & the toolkit

A random variable is a number whose value depends on chance — the payout of a bet, the number of deposits tomorrow. Discrete variables take countable values (0, 1, 2 wins); continuous ones take any value in a range (a $43.95 deposit, a 12.7-minute session).

3.2  Bernoulli & Binomial — the math of bets

A Bernoulli trial is a single yes/no event with success probability p: one bet wins or loses; one signup converts or doesn't. Add up n independent Bernoulli trials and you get the Binomial: the number of successes in n tries.

∑ Binomial
P(X = k) = C(n, k) · pᵏ · (1 − p)ⁿ⁻ᵏ mean = n·p std = √(n·p·(1−p))
"Out of n bets each with win-chance p, the probability of exactly k wins."
🎰 A 10-leg night
A sportsbook bettor places 10 independent bets, each winning with p ≈ 0.40 (our data's sportsbook win rate). How many do they win? That count is Binomial(n=10, p=0.40).
from scipy import stats n, p = 10, 0.40 dist = stats.binom(n, p) print("Expected wins (n*p):", dist.mean()) print("P(exactly 4 wins) :", round(dist.pmf(4), 4)) print("P(5 or more wins) :", round(dist.sf(4), 4)) # sf(4) = P(X > 4) = P(X >= 5) print("P(zero wins) :", round(dist.pmf(0), 4))
import matplotlib.pyplot as plt from scipy import stats n, p = 10, 0.40 k = range(0, n + 1) probs = stats.binom.pmf(k, n, p) fig, ax = plt.subplots(figsize=(8, 4)) ax.bar(k, probs, color="#36bcf7", edgecolor="white") ax.set_title(f"Binomial(n={n}, p={p}) — wins in a 10-bet night") ax.set_xlabel("number of winning bets"); ax.set_ylabel("probability") plt.show()
🧠 Where you'll really use this
The Binomial is the backbone of conversion analysis and A/B testing: if 200 visitors each convert with probability p, the number who convert is Binomial. That's how you'll reason about whether 38/200 vs. 51/200 is a real lift or just noise (Module 7).

3.3  Poisson — counts per period

The Poisson distribution models the number of events in a fixed window when events happen at a steady average rate, independently: deposits per day, bets per minute, support tickets per hour, goals per match. It has a single parameter λ (lambda) — the average count — and a signature property: its mean and variance are both equal to λ.

∑ Poisson
P(X = k) = e^(−λ) · λᵏ / k! mean = variance = λ

Let's estimate λ from data: the number of deposits the operator receives per day. First get the daily counts in SQL, then fit and test the Poisson in Python.

SELECT deposit_date, COUNT(*) AS deposits_that_day FROM deposits GROUP BY deposit_date ORDER BY deposit_date LIMIT 12;
import matplotlib.pyplot as plt from scipy import stats per_day = deposits.groupby(deposits["deposit_date"].dt.date).size() lam = per_day.mean() print(f"lambda (mean deposits/day): {lam:.2f}") print(f"variance: {per_day.var():.2f} (Poisson => ~equal to mean)") # Compare the observed histogram to the Poisson model kmax = per_day.max() ks = range(0, kmax + 1) fig, ax = plt.subplots(figsize=(8, 4)) ax.hist(per_day, bins=range(0, kmax + 2), density=True, align="left", color="#2a313c", edgecolor="white", label="observed") ax.plot(ks, stats.poisson.pmf(ks, lam), "o-", color="#36bcf7", label=f"Poisson(λ={lam:.1f})") ax.set_title("Deposits per day vs. a fitted Poisson") ax.set_xlabel("deposits in a day"); ax.set_ylabel("probability"); ax.legend() plt.show()

3.4  The Normal distribution

The Normal (Gaussian, "bell curve") is the most important distribution in statistics — not because raw data is often normal, but because averages of data are (that's the Central Limit Theorem, Module 4). It's defined by its mean μ and standard deviation σ.

∑ The 68–95–99.7 rule
≈68% of values fall within μ ± 1σ ≈95% of values fall within μ ± 2σ ≈99.7% of values fall within μ ± 3σ
A z-score rephrases any value as "how many σ from the mean": z = (x − μ) / σ.
🎰 Was yesterday's revenue unusual?
Daily GGR swings a lot (casino variance is real). If you know the mean and σ of daily GGR, a z-score instantly tells you whether a given day was a normal wobble or a genuine anomaly worth investigating.
import numpy as np from scipy import stats b = bets.copy() b["ggr"] = b["stake"] - b["payout"] daily = b.groupby(b["bet_date"].dt.date)["ggr"].sum() mu, sigma = daily.mean(), daily.std() print(f"daily GGR: mean ${mu:,.0f}, std ${sigma:,.0f}") # How extreme was the single best revenue day? best = daily.max() z = (best - mu) / sigma print(f"best day = ${best:,.0f} -> z = {z:.2f}") print(f"P(a day this high or higher under Normal) = {stats.norm.sf(z):.4f}")
import numpy as np, matplotlib.pyplot as plt from scipy import stats x = np.linspace(-4, 4, 400) fig, ax = plt.subplots(figsize=(8, 4)) ax.plot(x, stats.norm.pdf(x), color="#36bcf7", lw=2) for k, c in [(1, "#3fb950"), (2, "#d29922"), (3, "#f85149")]: ax.axvline(k, color=c, ls="--", lw=1); ax.axvline(-k, color=c, ls="--", lw=1) ax.set_title("Standard Normal — ±1σ (68%), ±2σ (95%), ±3σ (99.7%)") ax.set_xlabel("z (standard deviations from mean)"); ax.set_ylabel("density") plt.show() # Verify the rule with the CDF: for k in (1, 2, 3): inside = stats.norm.cdf(k) - stats.norm.cdf(-k) print(f"within ±{k}σ: {inside*100:.1f}%")

3.5  Exponential — waiting times

The Exponential distribution models the time between events that occur at a constant average rate — the flip side of the Poisson. If deposits arrive Poisson, the gap between a player's deposits is Exponential. Its tell-tale sign: mean ≈ standard deviation, and it's "memoryless."

∑ Exponential
pdf(x) = λ · e^(−λx) mean = 1/λ std = 1/λ
import matplotlib.pyplot as plt from scipy import stats dd = deposits.sort_values(["player_id", "deposit_date"]).copy() dd["gap_days"] = dd.groupby("player_id")["deposit_date"].diff().dt.days gaps = dd["gap_days"].dropna() print(f"mean gap: {gaps.mean():.2f} days, std: {gaps.std():.2f} days") print("mean ≈ std is the Exponential fingerprint.") rate = 1 / gaps.mean() x = range(0, int(gaps.quantile(0.99)) + 1) fig, ax = plt.subplots(figsize=(8, 4)) ax.hist(gaps, bins=30, density=True, color="#2a313c", edgecolor="white", label="observed") ax.plot(x, stats.expon.pdf(x, scale=1/rate), color="#7c5cff", lw=2, label="Exponential fit") ax.set_title("Time between deposits ~ Exponential") ax.set_xlabel("days between deposits"); ax.set_ylabel("density"); ax.legend() plt.show()

3.6  Log-normal — the shape of money

Back in Module 1 we saw deposits are right-skewed. That skew has a name: deposits (and stakes, and LTV) are approximately log-normal — their logarithm is normally distributed. Take the log of a skewed money column and a bell curve appears. This is why analysts so often model revenue on a log scale.

import numpy as np, matplotlib.pyplot as plt amt = deposits["amount"] fig, axes = plt.subplots(1, 2, figsize=(10, 4)) axes[0].hist(amt[amt < 400], bins=40, color="#36bcf7", edgecolor="white") axes[0].set_title("deposit amount (raw) — right-skewed") axes[1].hist(np.log(amt), bins=40, color="#7c5cff", edgecolor="white") axes[1].set_title("log(deposit amount) — bell-shaped") plt.show()
💡 Why this matters for your job
Means, t-tests, and linear regression all assume roughly symmetric data. Run them on raw deposits and a single whale can dominate the result. Run them on log(deposit) and they behave. "Log-transform skewed money before modeling" is one of the highest-ROI habits in analytics.

Exercises

✏️ Exercise 1 — Parlay probability
A 4-leg parlay wins only if all four legs win. If each leg wins independently with p = 0.45, what's the probability the parlay cashes? (Hint: this is P(X = 4) for a Binomial(4, 0.45), or just p⁴.)
from scipy import stats p = 0.45 # ...
Show solution
from scipy import stats p = 0.45 print("via binomial:", round(stats.binom.pmf(4, 4, p), 4)) print("via p**4 :", round(p**4, 4)) # ~0.041 — only ~4% of 4-leg parlays at these odds cash. That's the house edge compounding.
✏️ Exercise 2 — Poisson for support staffing
Suppose customer-support chats arrive at λ = 5 per hour (Poisson). What's the probability a given hour sees more than 8 chats — i.e. you might be understaffed?
from scipy import stats lam = 5 # P(X > 8) = sf(8)
Show solution
from scipy import stats lam = 5 print("P(>8 chats/hr):", round(stats.poisson.sf(8, lam), 4)) # ~0.068 — about 1 hour in 15 exceeds 8 chats. Staff for the tail, not the average.
🧠 Distribution cheat-sheet
  • Bernoulli / Binomial — yes/no outcomes & counts of successes (conversion, wins).
  • Poisson — counts per period at a steady rate (deposits/day, arrivals).
  • Normal — symmetric data & (crucially) averages; z-scores flag anomalies.
  • Exponential — waiting times between events (mean ≈ std).
  • Log-normal — skewed money (deposits, stakes, LTV); model on a log scale.
